# M3 Expressive 重构设计规范（v2 · 降噪版）

> 交付：`uipreview/` 模块（分支 `ui-builder`）
> 依赖：Compose BOM `2026.09.00`、`material3 1.5.0-rc01`
> 图标：Material Symbols Rounded（208 个 VectorDrawable，官方 symbols 端点导出）

---

## 0. 这次返工的根因

第一版的问题是**信息密度**，不是组件不会用：
一屏里同时出现「总览卡 + 统计 + 任务进度 + 筛选 + 分区标题 + FAB + 迷你播放器 + 底栏」，
每个元素都在抢注意力；进度波浪与按钮叠在一起、FAB 盖住筛选 chip、播放器副标题压在封面上。

v2 用四条硬规则重做：

| 规则 | 具体约束 |
|---|---|
| **一屏三块** | 首屏最多 3 个信息块（1 个主视觉 + 2 个辅助），其余进二级页或 Sheet |
| **单一锚点** | 一屏只有一个强调色区域；其余用 `surface` / `surfaceContainerLow` 的中性层次 |
| **不叠元素** | 任何进度/装饰不得与可点元素重叠：进度一律放在定高容器内裁剪 |
| **主操作唯一** | 一屏最多一个实心主按钮；次要操作进顶栏图标、菜单或 Sheet |

## 1. 色彩

| 项 | 决策 |
|---|---|
| 主策略 | 动态取色优先（API 31+），关闭后回退暖中性 + 深墨绿 |
| 用法 | 只用语义 role；`design/`、`screens/` 中 0 处 `Color(0xFF…)` |
| 强调 | `primary`：主按钮/进度/当前态；`secondaryContainer`：选中/信息；`tertiaryContainer`：仅实验室标注；`error`：破坏性 |
| 层次 | 页面底 `background`；摘要卡 `surfaceContainerLow`；无边框、无阴影堆叠 |

回退色（关键 role）：
```
light  primary #1F6B45  primaryContainer #A8F5C8  background #FBF8F3
       surfaceContainerLow #F5F2EC  outlineVariant #C3C8BC
dark   primary #8BD8AB  primaryContainer #005232  background #12140F
       surfaceContainerLow #1A1C17  outlineVariant #43483F
```

## 2. 字体

| 场景 | Token |
|---|---|
| 页面标题 | `headlineSmallEmphasized`（顶栏，滚动折叠到 `titleLarge`） |
| 分区标签 | `labelMedium` + `letterSpacing 0.8sp` + `onSurfaceVariant`（**不再用 22sp 区块大标题**） |
| 列表主行 | `titleMedium`（16sp） |
| 辅助信息 | `bodySmall`（12sp）+ `onSurfaceVariant` |
| 正文/台词 | `bodyLarge`（16sp，台词行高 27sp） |
| 数字 | 统计用 `labelLarge`；只有存储总量与播放器书名用 `displaySmall` |
| 按钮 | `labelLarge` |

字号 100% / 130% / 200% 三档可切；只放大 sp，不放大图标与触控区。

## 3. 形状 / 间距 / 动效

| Token | 值 | 用途 |
|---|---|---|
| `extraSmall` | 8dp | SpecTag |
| `medium` | 16dp | 次级动作块 |
| `large` | 24dp | 当前台词高亮块 |
| `extraLarge` | 32dp | 摘要卡 / Sheet 内容块 |
| `extraExtraLarge` | 40dp | Sheet 容器 |
| `CoverShape` | 28/12/28/12 | 封面（不对称） |
| 胶囊 | `CircleShape` | 按钮 / chip / 头像 |

间距：屏幕左右 **20dp**；区块间距 **28dp**；列表行最小 **64dp**；触控 ≥48dp。

动效：`MotionScheme.expressive()`；页面转场用 `defaultSpatialSpec` 的水平位移 + 淡入；
加载用 M3 `LoadingIndicator`（多边形形变）；进度用波浪条（仅在摘要与播放器出现）。

## 4. 组件层（`design/`）

| 组件 | 说明 |
|---|---|
| `AppTopBar` | `MediumFlexibleTopAppBar`：展开两行（标题+副标题），滚动折叠；返回 48dp |
| `SectionLabel` | 12sp 分区标签 + 可选尾随计数；可挂 `SpecTag` |
| `ListRow` | 36dp 图标底 + 主/副标题 + 尾随值 + Chevron；整行可点；≥64dp |
| `RowDivider` | 1dp、`outlineVariant` 55%，左右 20dp 缩进 |
| `QuietCard` | 整页最多一张的摘要卡（`surfaceContainerLow` + 32dp 圆角） |
| `StatusChip` / `StatusDot` | 胶囊用于需要文字的场合；列表行用 7dp 圆点 |
| `ProgressLine` | 波浪进度，**固定 18dp 高并裁剪**，不会压到相邻按钮 |
| `ThinProgress` | 3dp 细进度（列表行内） |
| `PrimaryButton` / `SecondaryButton` | 图标 + 文字，56/52dp |
| `IconAction` | 48dp，描述必填 |
| `EmptyState` / `ErrorState` / `LoadingState` | 88dp 容器 + 唯一主操作；错误态解释原因 |
| `SheetHeader` | 40dp 图标底 + 标题 + 副标题 + 关闭 |
| `ConfirmDialog` | 危险操作统一入口 |
| `CoverArt` | 三色渐变 + 首字 + 不对称圆角 |
| `SpecTag` | 实验室「显示设计规范」时才渲染 |

**禁止**：纯文字可点元素、无描述图标按钮、`Color(0xFF`、进度与按钮重叠、FAB 覆盖列表。

## 5. 信息架构（2 tabs 定稿）

```
书架（tab 1）
├─ 继续收听（唯一摘要卡）→ 播放器
├─ 任务行（1 行，仅运行中）→ 任务页
├─ 项目列表 → 项目详情
│    ├─ 章节前 4 行 / 查看全部 → 章节 → 剧本 → 片段编辑 Sheet
│    ├─ 人物条 → 人物与音色 → 音色选择 / 微调 Sheet
│    ├─ 继续生成 → 批量生成 Sheet
│    └─ 更多 → 导出 Sheet / 分享 / 删除
└─ 顶栏：搜索（展开搜索 + 筛选）/ 导入 / 排序菜单

设置（tab 2）
├─ 外观（主题 / 字号 / 动态取色，即时生效）
├─ 模型与密钥 → 二级页（Base URL / 模型 / Key 编辑）
├─ 生成默认值 → 二级页（5 个滑杆）
├─ 网络与设备 → 二级页（4 开关 + 电量阈值）
├─ 数据与存储 → 存储页（分区 / 保留期 / 清理）
├─ 关于 → 关于页（诊断 / 许可 / 复制）
└─ 预览工具：设计实验室 / 重新观看引导

全屏：播放器、首次引导
```

底栏只在两个 tab 根页出现。

**迷你播放器规则（v2.1）**：
- 默认不出现；只有真正开始过播放（`hasSession`）后才出现，暂停时保留；
- 只在内容页出现：书架、项目详情、章节、剧本；
- 设置、人物、任务、存储、关于、模型/生成/网络、引导、播放器、实验室一律不显示；
- 没有「未在播放」占位条。

## 7. 交互规范

| 行为 | 规范 |
|---|---|
| 点击列表行 | 进入下一层；行内不再重复放一个同义箭头按钮 |
| 长按 | 只在剧本（复制台词）与章节（多选）使用；触发后必须有可见反馈 |
| 多选 | 章节长按进入多选 → 底部浮动工具条（关闭 / 已选 N / 全选 / 生成 / 导出） |
| 危险操作 | 删除项目、停止任务、清理文件：一律 `ConfirmDialog`，确认按钮用 error 色 |
| 编辑 | 值编辑用 Sheet（带说明「只存本机」），保存后 Snackbar 确认 |
| 播放 | 迷你播放器与播放器共享状态；点击封面区进入播放器；播放器下拉/返回退出 |
| 搜索 | 顶栏图标展开内联搜索并自动聚焦；清空/关闭恢复列表 |
| 加载/空/错 | 每页可独立切换（设计实验室），状态块居中、带唯一行动 |
| 手势 | 播放器进度可拖；返回手势走系统预测返回（`BackHandler` + `Navigator`） |

## 8. 无障碍

- 触控 ≥48dp（`IconAction` 显式 48dp，`ListRow` ≥64dp）。
- 标题 `heading()`；图标按钮描述必填；装饰图标 `contentDescription = null`。
- 进度组件自带 `progressBarRangeInfo`；播放进度另有时间文案。
- 200% 字号：分段选择退化为可换行 chip；按钮竖排；列表行自动增高。
- 深浅色均使用语义 role，正文对比度 ≥4.5:1。

## 11. v2.2：导航、转场与交互修正

### 11.1 两个 tab 是平行页，不是两条互相覆盖的栈

- 书架与设置各自维护一条返回栈（`Navigator.tabStacks`），切走再切回仍停在原页。
- tab 之间用 **fade through**（旧页 90ms 淡出 → 新页 210ms 淡入 + 0.97 缩放），不做左右位移；只有栈内 push/pop 才是方向性滑动（进 280ms / 出 220ms）。
- 栈内页面用 `rememberSaveableStateHolder` 保滚动位置；返回键优先级：先退模式（搜索/多选）→ 再退页面 → 再回书架 tab → 最后才退出。

### 11.2 一屏三块的具体落点

| 页面 | 第一块 | 第二块 | 第三块 | 其余去哪 |
|---|---|---|---|---|
| 书架 | 继续收听（仅未开播时） | 生成中任务一行 | 项目列表 | 导入 → 面板；排序 → 顶栏 |
| 项目 | 封面 + 进度 | 主操作「继续生成」 | 章节列表 | 人物 → 人物页；导出/删除 → 顶栏菜单 |
| 章节 | 搜索（按需） | 列表 | 选择工具条（多选时） | 筛选 → 顶栏漏斗 |
| 剧本 | 角色筛选（一个按钮） | 台词列表 | 迷你播放器 | 编辑 → 面板 |
| 播放器 | 封面 + 标题 | 当前台词 | 进度 + 传输键 | 倍速/睡眠/连播 → 顶栏菜单；章节 → 标题下 |
| 设置 | 外观 | 5 个二级入口 | 预览工具 | 全部二级页 |
| 存储 | 占用条 + 图例 | 项目占用 | 保留期 | 清理 → 顶栏菜单 |
| 关于 | 品牌 | 运行检查 | 开源许可 | 明细 → 面板 |

### 11.3 面板（sheet）排版

- `SheetHeader` 自身不再带水平内边距；水平 24dp 只由外层容器给一次，标题与列表、主按钮左对齐。
- 编辑类面板（改地址/Key/台词）统一：标题 + 说明 + 字段 + 主按钮，输入框自动聚焦并 `imePadding()`。

### 11.4 高频控件的触控目标

- 所有图标按钮 48dp（迷你播放器、剧本行内播放/编辑、搜索清除）。
- 播放器主键在「当前段无音频」时降透明度且不可点，不再出现「点了没反应」。
- 长按类操作补 `HapticFeedbackType.LongPress`。
